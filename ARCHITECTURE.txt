PROJECT TYPE: Full-Stack Web Application (Node.js taxonomy)
FRAMEWORK: NestJS

BUILD COMMANDS
==============
npm install
npm run build     # tsc compiles src/*.ts -> dist/
npm start          # runs the compiled dist/main.js
npm test           # jest e2e test against a real NestJS TestingModule

ARCHITECTURE
============
A real minimal NestJS application - Module/Controller/Service structure (the
canonical Nest architecture used for full-stack backends), written in TypeScript
with decorators (@Module/@Controller/@Injectable), tested via @nestjs/testing's
TestingModule + supertest against the real HTTP server.

  src/app.module.ts        root module
  src/app.controller.ts    HTTP routes (/health, /api/widgets)
  src/widgets.service.ts   injectable service holding the data
  src/main.ts              bootstrap
  test/app.e2e-spec.ts     jest e2e tests via NestJS TestingModule
