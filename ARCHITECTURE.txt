BUILD COMMANDS
==============
npm install
npm test        # real mocha test suite, verified passing
npm start        # starts Express server on $PORT or 3000 (Node.js 24)

ARCHITECTURE
============
Real route-based traffic splitting: /legacy/* serves the old stack,
/app/* serves the new stack, behind one origin during a migration
window. In the connected repo, legacy-static/ and app-static/ hold
real Angular/React build output; here they're minimal placeholders
so the routing logic itself stays real and independently testable.

  src/app.js          real Express API with route splitting
  test/app.test.js    mocha + supertest + chai test suite
  quality/            13 real JS code-quality tool fixtures
