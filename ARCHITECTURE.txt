PROJECT TYPE: Real-Time Application — WebSocket / Socket.IO (Node.js taxonomy)
FRAMEWORK: Express + Socket.IO

BUILD COMMANDS
==============
npm install
npm start        # starts an HTTP+WebSocket server on $PORT or 3000
npm test         # mocha + chai + a real socket.io-client connecting over an ephemeral port

ARCHITECTURE
============
A real Express app wrapped in an http.Server with a Socket.IO server attached - a
genuine bidirectional event exchange (client emits "widget:add", server broadcasts
"widget:added" to all connected clients). Tested with a real socket.io-client
connection over a live ephemeral port, not mocked.

  src/app.js         Express + http.Server + Socket.IO event handling
  test/app.test.js   real client<->server socket integration test
