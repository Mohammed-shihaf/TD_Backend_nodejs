==============

ARCHITECTURE
============
One backend, two API namespaces:
  /api/customer/*   public, consumed by the React storefront
  /api/admin/*      internal, consumed by the Angular admin app
The React and Angular frontends live in TD_Frontend_reactjs and
TD_Frontend_angularjs, branched under the same saasplatform name -
each only calls its own namespace.

  src/app.js          real Express API with both namespaces
  test/app.test.js    mocha + supertest + chai test suite
  quality/            13 real JS code-quality tool fixtures
