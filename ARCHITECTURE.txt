PROJECT TYPE: Design-System Cross-Framework Test Harness (standalone backend module)
(extracted from the connected TD_Designsystemharness_BE_nodejs_FE_reactjs_FE_angularjs- repo)

BUILD COMMANDS
==============
npm install
npm test        # real mocha test suite, verified passing
npm start        # starts Express server on $PORT or 3000 (Node.js 20)

ARCHITECTURE
============
Single source of truth for design tokens (color/spacing/typography),
served at GET /api/design-tokens. Both the React and Angular frontends
(TD_Frontend_reactjs / TD_Frontend_angularjs, same designsystemharness
branch name) fetch these same tokens and are parity-tested against
each other's rendered output.

  src/app.js          real Express API serving shared tokens
  test/app.test.js    mocha + supertest + chai test suite
  quality/            13 real JS code-quality tool fixtures
