PROJECT TYPE: CLI / Command-Line Application (Node.js taxonomy)
FRAMEWORK: Commander.js (CLI) + Koa (HTTP surface for the "serve" subcommand)

BUILD COMMANDS
==============
npm install
node src/cli.js list --json   # real CLI invocation
npm test                       # mocha + chai, invoking the CLI programmatically + real HTTP test of "serve"

ARCHITECTURE
============
A real CLI with two subcommands, built with Commander.js:
  - `list` - prints widgets (human-readable or --json)
  - `serve` - starts a real Koa HTTP server exposing the same data
This matches the taxonomy's framework guidance directly (Koa for any HTTP surface,
Commander.js for the actual CLI), combining both in one small tool.

  src/widgets.js   shared data module
  src/cli.js       Commander.js CLI (list, serve)
  src/server.js    Koa server used by "serve"
  test/app.test.js tests: CLI output via programmatic invocation + real HTTP request to the Koa server
