PROJECT TYPE: REST API / Backend Service (Node.js taxonomy)
FRAMEWORK: Express.js

BUILD COMMANDS
==============
npm install
npm start        # starts Express server on $PORT or 3000
npm test         # mocha + chai + supertest, real HTTP integration tests

ARCHITECTURE
============
A real minimal REST API - a /api/widgets resource with GET (list + by-id), POST
(create, with validation), DELETE, plus /health. Express.js is chosen as the most
common, minimal-overhead framework for this exact taxonomy category.

  src/app.js         Express app with a real CRUD-style resource
  test/app.test.js   supertest integration tests against every route
