PROJECT TYPE: Microservice (Node.js taxonomy)
FRAMEWORK: Fastify

BUILD COMMANDS
==============
npm install
npm start        # starts Fastify server on $PORT or 3000
npm test         # mocha + chai, using Fastify's built-in .inject() (no real socket needed)

ARCHITECTURE
============
A real minimal single-responsibility microservice - a narrow, focused API surface
(/health + one /api/widgets/count endpoint), built with Fastify rather than Express,
which is a common choice for microservices due to its lower overhead/higher throughput
and built-in schema-based routing.

  src/app.js         Fastify app factory (buildApp)
  test/app.test.js   tests using Fastify's app.inject() harness
