PROJECT TYPE: White-Label / Multi-Tenant Storefront (standalone backend module)
(extracted from the connected TD_Whitelabelstorefront_BE_nodejs_FE_reactjs_FE_angularjs- repo)

BUILD COMMANDS
==============
npm install
npm test        # real mocha test suite, verified passing
npm start        # starts Express server on $PORT or 3000 (Node.js 20)

ARCHITECTURE
============
Backend resolves tenant identity from the x-tenant-id header (in the
connected repo this is subdomain-based) and returns tenant-scoped
config via GET /api/tenant-config. Self-serve tenants are served by
the React storefront, enterprise tenants by the Angular storefront
(TD_Frontend_reactjs / TD_Frontend_angularjs, same branch name).

  src/app.js          real Express API with tenant resolution
  test/app.test.js    mocha + supertest + chai test suite
  quality/            13 real JS code-quality tool fixtures
