PROJECT TYPE: Micro-Frontend Platform (standalone backend module)

BUILD COMMANDS
==============
npm install
npm test        # runs mocha test suite (real, verified passing)
npm start        # starts Express server on $PORT or 3000 (Node.js 22)

ARCHITECTURE
============
This is a STANDALONE Node.js backend repo - Express only, no frontend.
It exists separately from the TD_*_BE_nodejs_FE_reactjs_FE_angularjs
connected project-type repos, which combine backend + React + Angular
into single connected applications. This repo is the backend module in
isolation, branched per Node.js version - but a genuine multi-resource
API, not a single bare route.

  src/app.js                mounts routers, GET /health
  src/routes/widgets.js      GET/POST /api/widgets, GET /api/widgets/:id
  src/routes/remotes.js      GET /api/remotes (embeddable-remote registry;
                              mirrors the connected repo's iframe target)
  src/data/widgets.js        in-memory CRUD-lite data layer
  test/                      widgets.test.js, remotes.test.js, health.test.js
  quality/                   13 real JS code-quality tool fixtures
                              (eslint, nyc, jscpd, lizard, mocha, npm-audit,
                              npm-cli, npm-ls, stryker-js, diff-cover,
                              pydriller, eslint-plugin-security,
                              eslint-plugin-sonarjs)

Branches: microfrontend_nodejs<18|20|22|24> - one per Node.js version,
each independently `npm install` + `npm test` verified.
