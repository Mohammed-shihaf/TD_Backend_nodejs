# TD_Backend_nodejs

Standalone Node.js (Express) backend - not connected to any frontend.
Separate from the TD_*_BE_nodejs_FE_reactjs_FE_angularjs connected
project-type repos, which combine backend+React+Angular together.

See ARCHITECTURE.txt for build commands and module layout.

Branches: one per Node.js version (18, 20, 22, 24).
